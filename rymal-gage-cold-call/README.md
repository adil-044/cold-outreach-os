## Full run-through

### Gatekeeper

Capture: name · role · callback window · email if offered.

### Decision-maker

1. Winner B opener  
2. “Mind if I name one spot, or want the list by email?”  
3. Ask 4–5 questions (table below)  
4. Soft close → free fix list to support@

### Questions

| # | Ask | Why |
|---|---|---|
| 1 | Who updates the site today — you, staff, or an old designer? | Owner map |
| 2 | New patients mostly Google / referrals / both? | Pain weight |
| 3 | Should every Google click reach (905) 388-9088 only? | NAP / phone |

| 5 | Online booking live, or call-only? | Later upsell |
| 6 | If we fix phone + NAP this week, who approves? | Close path |
